## Đề bài

Nhập vào một chuỗi ký tự và in ra chuỗi theo thứ tự ngược lại.

### Input

- Một dòng chứa chuỗi ký tự có độ dài $L$ không quá 1000.

### Output

- In ra chuỗi được sắp xếp theo thứ tự ngược.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
hniB nA ihP narT
```

#### Input 2

```
Tien Giang
```

#### Output 2

```
gnaiG neiT
```

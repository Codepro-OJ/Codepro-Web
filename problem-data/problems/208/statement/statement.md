## Đề bài

Nhập vào một chuỗi s, một ký tự x, và số nguyên n. Thêm các ký tự x vào bên phải chuỗi s sao cho tổng độ dài của chuỗi mới là n, và chuỗi s nằm ở bên trái.

### Input

- Dòng 1: Chuỗi s có độ dài không quá 1000 ký tự.

- Dòng 2: Ký tự x.

- Dòng 3: Số nguyên n (n ≥ độ dài của s và n ≤ 2000).

### Output

- Chuỗi mới với s nằm ở bên trái và đủ độ dài n.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
&
20
```

#### Output 1

```
Tran Phi An Binh&&&&
```

#### Input 2

```
Tien Giang
$
13
```

#### Output 2

```
Tien Giang$$$
```

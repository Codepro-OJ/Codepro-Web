## Đề bài

Nhập vào một số nguyên $n$, hãy cho biết $n$ có bao nhiêu chữ số (không sử dụng hàm $\log(n,e)$ và không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($ 0 < n < 10^{19}$).

### Output

- Số lượng chữ số của $n$.

### Ví dụ

#### Input 1

```
31122023
```

#### Output 1

```
8
```

#### Input 2

```
2009
```

#### Output 2

```
4
```

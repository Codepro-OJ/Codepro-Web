## Đề bài

Nhập vào một mảng $a$ có $n$ số nguyên: $a_0, a_1, a_2, \dots, a_{n-1}$. Tính tổng các số nguyên tố trong mảng.

### Input

- Dòng thứ nhất: Một số nguyên $n$ ($0 < n < 10^6$).

- $n$ dòng tiếp theo: Mỗi dòng chứa một số nguyên có giá trị tuyệt đối không vượt quá $10^5$.

### Output

- Tổng các số nguyên tố trong mảng.

### Ví dụ

#### Input 1

```
7
9
6
3
8
10
7
-2
```

#### Output 1

```
10
```

#### Input 2

```
5
7
3
8
0
2
```

#### Output 2

```
12
```

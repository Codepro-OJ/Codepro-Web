## Đề bài

Nhập vào cân nặng của một người (tính bằng kg), nếu cân nặng > 80 thì in ra Béo phì, nếu cân nặng < 45 thì in ra Suy dinh dưỡng, còn lại là Bình thường.

✅ (Sử dụng if ... else...)

### Input

- Một số nguyên dương n (0 < n < 200) là cân nặng của một người.

### Output

- Kết quả là Beo phi hoặc Suy dinh duong hoặc Binh thuong.

### Ví dụ

#### Input 1

```
91
```

#### Output 1

```
Beo phi
```

#### Input 2

```
22
```

#### Output 2

```
Suy dinh duong
```

#### Input 3

```
50
```

#### Output 3

```
Binh thuong
```

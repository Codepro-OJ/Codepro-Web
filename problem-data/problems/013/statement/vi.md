## Đề bài

Nhập vào một số nguyên $a$ có 4 chữ số. Tính tổng các chữ số của $a$.

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Một số nguyên $a$ $(1000 \leq a \leq 9999)$.

### Output

- Một số nguyên là kết quả của bài toán.

### Ví dụ

#### Input 1

```
1234
```

#### Output 1

```
10
```

#### Input 2

```
5067
```

#### Output 2

```
18
```

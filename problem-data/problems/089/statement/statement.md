## Đề bài

Nhập vào một số nguyên $n$, hãy đếm số lượng các chữ số lẻ của $n$ (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($0 < n < 10^{19}$).

### Output

- Một số nguyên là số lượng chữ số lẻ của $n$.

### Ví dụ

#### Input 1

```
31121987
```

#### Output 1

```
6
```

#### Input 2

```
2014
```

#### Output 2

```
1
```

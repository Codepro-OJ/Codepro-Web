## Đề bài

Nhập vào một số nguyên dương $n$. Kiểm tra xem $n$ có phải là số hoàn hảo hay không. 
Một số $n$ được gọi là số hoàn hảo nếu tổng các ước (không tính $n$) của $n$ bằng chính nó. Ví dụ: n = 6 có tổng các ước là 1 + 2 + 3 = 6 nên n là số hoàn hảo. Số n = 8 có tổng các ước là 1 + 2 + 4 = 7 khác 8 nên n không phải số hoàn hảo

### Input

- Một số nguyên dương $n$ ($0 < n < 10^9$).

### Output

- Yes nếu $n$ là số hoàn hảo.

- No nếu $n$ không phải là số hoàn hảo.

### Ví dụ

#### Input 1

```
6
```

#### Output 1

```
Yes
```

#### Input 2

```
8
```

#### Output 2

```
No
```

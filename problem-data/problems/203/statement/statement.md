## Đề bài

Nhập vào một chuỗi và tìm ký tự chữ cái có mã ASCII nhỏ nhất trong chuỗi đó.

### Input

- Một dòng chứa chuỗi ký tự s có độ dài không quá 1000 ký tự.

### Output

- In ra ký tự chữ cái có mã ASCII nhỏ nhất, dấu hai chấm (:), dấu cách và giá trị mã ASCII tương ứng.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
A: 65
```

#### Input 2

```
Viet Nam
```

#### Output 2

```
N: 78
```

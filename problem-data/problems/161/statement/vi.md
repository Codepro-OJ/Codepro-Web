## Đề bài

Nhập vào một chuỗi ký tự và một số nguyên $k$. In ra ký tự tại vị trí $k$ trong chuỗi (chỉ số bắt đầu từ 0).

### Input

- Dòng đầu tiên chứa một chuỗi ký tự có độ dài $L$ không quá 1000.

- Dòng thứ hai chứa một số nguyên $k$ ($0 \leq k < L$).

### Output

- Ký tự tại vị trí $k$ trong chuỗi.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
1
```

#### Output 1

```
r
```

#### Input 2

```
Tran Phi Binh An
9
```

#### Output 2

```
B
```

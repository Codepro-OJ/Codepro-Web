## Đề bài

Nhập vào hai số nguyên $m$ và $n$ ($m \leq n$). Tính tổng các số chẵn từ $m$ đến $n$.

### Input

- Hai số nguyên dương $m$ và $n$ ($0 < m \leq n < 10^6$).

- Hai số được nhập trên cùng một dòng, cách nhau bởi dấu cách.

### Output

- Một số duy nhất là tổng các số nguyên chẵn từ $m$ đến $n$.

### Ví dụ

#### Input 1

```
11 15
```

#### Output 1

```
26
```

#### Input 2

```
2 9
```

#### Output 2

```
20
```

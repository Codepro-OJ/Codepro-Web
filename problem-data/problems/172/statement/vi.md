## Đề bài

Nhập vào hai chuỗi $s1$ và $s2$. Nối chuỗi $s2$ vào cuối chuỗi $s1$ và in ra chuỗi kết quả.

### Input

- Dòng đầu tiên chứa chuỗi $s1$ có độ dài không quá 1000.

- Dòng thứ hai chứa chuỗi $s2$ có độ dài không quá 1000.

### Output

- In chuỗi kết quả sau khi nối chuỗi $s2$ vào cuối chuỗi $s1$.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
Tien Giang
```

#### Output 1

```
Tran Phi An BinhTien Giang
```

#### Input 2

```
Vinh Kim
Viet Nam
```

#### Output 2

```
Vinh KimViet Nam
```

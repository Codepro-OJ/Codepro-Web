## Đề bài

Nhập vào một số nguyên dương $a$ có 8 chữ số. Tính tổng các chữ số chẵn của $a$.

### Input:

- Một số nguyên dương $a$ có 8 chữ số.

### Output

- Tổng các chữ số chẵn của a hoặc dấu "-" nếu không có chữ số chẵn.

### Ví dụ

#### Input 1

```
14102004
```

#### Output 1

```
10
```

#### Input 2

```
15111977
```

#### Output 2

```
-
```

## Đề bài

Nhập vào một mảng $a$ có $n$ số nguyên: $a_0, a_1, a_2, \dots, a_{n-1}$. Tìm giá trị nhỏ nhất trong mảng $a$ và vị trí đầu tiên của giá trị nhỏ nhất đó.

### Input

- Dòng thứ nhất: Một số nguyên $n$ ($0 < n < 10^6$).

- $n$ dòng tiếp theo: Mỗi dòng chứa một số nguyên có giá trị tuyệt đối không vượt quá $10^5$.

### Output

- Dòng đầu tiên: Giá trị nhỏ nhất trong mảng.

- Dòng thứ hai: Vị trí đầu tiên của giá trị nhỏ nhất trong mảng (tính từ 0).

### Ví dụ

#### Input 1

```
7
9
6
3
-2
8
7
-2
```

#### Output 1

```
-2
3
```

#### Input 2

```
5
15
0
20
7
10
```

#### Output 2

```
0
1
```

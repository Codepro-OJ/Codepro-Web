## Đề bài

Nhập vào một số tự nhiên $n$. In ra những số tự nhiên từ 1 đến $n$.

### Input

- Một số tự nhiên $n$ ($0 < n < 10^6$).

### Output

- Các số từ 1 đến $n$ trên một dòng, phân tách nhau bởi dấu cách.

### Ví dụ

#### Input 1

```
3
```

#### Output 1

```
1 2 3
```

#### Input 2

```
6
```

#### Output 2

```
1 2 3 4 5 6
```

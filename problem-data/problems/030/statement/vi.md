## Đề bài

Nhập vào chu vi của một hình vuông, tính diện tích hình vuông đó. Biết rằng cạnh hình vuông là số nguyên (Tính cạnh lấy phần nguyên trước rồi tính diện tích)

### Input

- Một số nguyên $a$ $(0 < a < 10^9)$ là chu vi của một hình vuông.

### Output

- Diện tích của hình vuông đó.

### Ví dụ

#### Input 1

```
8
```

#### Output 1

```
4
```

#### Input 2

```
12
```

#### Output 2

```
9
```

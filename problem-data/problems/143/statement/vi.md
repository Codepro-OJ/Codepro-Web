## Đề bài

Nhập vào một mảng số nguyên $a: a_0, a_1, a_2, \dots$. Tính tổng các số âm trong mảng.

### Input

- Một dòng chứa các số nguyên có giá trị tuyệt đối không vượt quá $10^5$, cách nhau bởi dấu cách.

- Số lượng phần tử không quá $10^6$.

### Output

- Một số nguyên là tổng các số âm trong mảng.

### Ví dụ

#### Input 1

```
9 -6 3 8 10 -7 -2
```

#### Output 1

```
-15
```

#### Input 2

```
7 3 8 0 2
```

#### Output 2

```
0
```

## Đề bài

Nhập vào hai chuỗi s1 và s2, kiểm tra xem chuỗi s1 có bắt đầu bằng chuỗi s2 hay không. Nếu đúng, in Yes, ngược lại in No.

### Input

- Dòng một: Chuỗi s1 có độ dài không quá 1000 ký tự.

- Dòng hai: Chuỗi s2 có độ dài không quá 1000 ký tự.

### Output

- In Yes nếu s1 bắt đầu bằng s2.

- In No nếu không.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
Tran
```

#### Output 1

```
Yes
```

#### Input 2

```
Vinh Kim Tien Giang
Tien
```

#### Output 2

```
No
```

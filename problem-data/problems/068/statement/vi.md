## Đề bài

Nhập vào một số tự nhiên $n$. Tính trung bình cộng những số tự nhiên chẵn từ 1 đến $n$.

### Input

- Một số tự nhiên $n$ ($0 < n < 10^6$).

### Output

- Một số thực là trung bình cộng các số tự nhiên chẵn từ 1 đến $n$, có không chữ số thập phân.

- Nếu không có số chẵn nào thì in $0$.

### Ví dụ

#### Input 1

```
13
```

#### Output 1

```
7
```

#### Input 2

```
21
```

#### Output 2

```
11
```

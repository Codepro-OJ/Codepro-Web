## Đề bài

Nhập vào một số nguyên $a$, kiểm tra xem $a$ là:

- Số dương (So duong)

- Số âm (So am)

- Hay số 0 (So khong)

✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Một số nguyên $a$ $( |a| ≤ 10^9 )$.

### Output

- Một dòng là So duong, So am hoặc So khong.

### Ví dụ

#### Input 1

```
5
```

#### Output 1

```
So duong
```

#### Input 2

```
-3
```

#### Output 2

```
So am
```

#### Input 3

```
0
```

#### Output 3

```
So khong
```

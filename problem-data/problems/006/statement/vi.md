## Đề bài

Cho một số thực không âm $a$, hãy tính $B = \sqrt{a}$ và in kết quả ra màn hình với hai chữ số thập phân.

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Một số thực $a$ $(0 \le a \le 10^9)$.

### Output

- Một số thực là kết quả của B, có hai chữ số thập phân.

### Ví dụ

#### Input 1

```
15
```

#### Output 1

```
3.87
```

#### Input 2

```
7
```

#### Output 2

```
2.65
```

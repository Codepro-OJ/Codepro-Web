## Đề bài

Nhập vào một chuỗi và kiểm tra xem tất cả các ký tự chữ cái trong chuỗi đó có phải là ký tự viết thường hay không. Nếu tất cả đều là ký tự viết thường, in YES, ngược lại in NO.

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000.

### Output

- In YES nếu tất cả các ký tự chữ cái trong chuỗi là ký tự viết thường.

- In NO nếu có ít nhất một ký tự chữ cái không phải là ký tự viết thường.

### Ví dụ

#### Input 1

```
tran phi an binh
```

#### Output 1

```
YES
```

#### Input 2

```
Tran Phi An Binh
```

#### Output 2

```
NO
```

#### Input 3

```
hello world!
```

#### Output 3

```
YES
```

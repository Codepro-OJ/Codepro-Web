## Đề bài

Nhập vào một số nguyên $n$, hãy in các chữ số của $n$ theo thứ tự ngược lại (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($0 < n < 10^{19}$).

### Output

- Số đảo ngược của $n$.

### Ví dụ

#### Input 1

```
31121987
```

#### Output 1

```
78912113
```

#### Input 2

```
2030
```

#### Output 2

```
302
```

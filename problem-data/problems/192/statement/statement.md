## Đề bài

Nhập vào một chuỗi và xoá tất cả các khoảng trắng thừa ở đầu chuỗi.

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000 (Trong chuỗi không có dấu).

### Output

- In ra chuỗi sau khi đã xoá khoảng trắng thừa ở đầu (không có dấu).

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
Tran Phi An Binh
```

#### Input 2

```
Vinh Kim
```

#### Output 2

```
Vinh Kim
```

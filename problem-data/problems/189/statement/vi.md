## Đề bài

Nhập vào một chuỗi và một ký tự x, đếm số lần ký tự x xuất hiện trong chuỗi.

### Input

- Dòng một: Một chuỗi ký tự có độ dài không quá 1000.

- Dòng hai: Một ký tự x cần đếm.

### Output

- In ra số lần ký tự x xuất hiện trong chuỗi.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
n
```

#### Output 1

```
3
```

#### Input 2

```
Vinh Kim Tien Giang
Z
```

#### Output 2

```
0
```

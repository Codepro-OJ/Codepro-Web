## Đề bài

Nhập vào một số tự nhiên $n$. Tính trung bình cộng những số tự nhiên chia hết cho 5 từ 1 đến $n$.

### Input

- Một số tự nhiên $n$ ($0 < n < 10^6$).

### Output

- Một số thực là trung bình cộng các số tự nhiên chia hết cho 5 từ 1 đến $n$, có một chữ số thập phân.

- Nếu không có số chia hết cho 5 nào thì in $0.0$.

### Ví dụ

#### Input 1

```
13
```

#### Output 1

```
7.5
```

#### Input 2

```
21
```

#### Output 2

```
12.5
```

## Đề bài

Nhập vào một chuỗi ký tự và in ra ký tự cuối cùng trong chuỗi.

### Input

- Một dòng chứa chuỗi ký tự có độ dài $L$ không quá 1000.

### Output

- Ký tự cuối cùng trong chuỗi.

### Ví dụ

#### Input 1

```
Tran Phi An Binh Vinh Kim
```

#### Output 1

```
m
```

#### Input 2

```
Tran Phi Bình An Tien Giang
```

#### Output 2

```
g
```

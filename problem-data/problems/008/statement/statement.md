## Đề bài

Cho hai số nguyên $a$ và $b$, hãy tính các biểu thức:

- $P = 21a + 5b - 2009$

- $Q = \frac{21a^2 - 5b}{2009b^2}$

- $R = \frac{21a + 5b^2}{2009b + 15}$

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Hai số nguyên $a, b$ $(|a|, |b| \le 10^9)$, mỗi số một dòng.

### Output

- Dòng một là $P$ và $Q$, cách nhau bởi dấu cách, $Q$ có bốn chữ số thập phân.

- Dòng hai là $R$, có sáu chữ số thập phân.

### Ví dụ

#### Input 1

```
2
3
```

#### Output 1

```
-1952 0.0038
0.014399
```

#### Input 2

```
7
10
```

#### Output 2

```
-1812 0.0049
0.032181
```

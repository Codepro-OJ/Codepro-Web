## Đề bài

Nhập vào một số nguyên n, hãy tính tổng các chữ số chẵn của n (không sử dụng kiểu string)

### Input

- Một số nguyên dương $n$ $(0 < n < 10^{19})$

### Output

- Tổng các chữ số chẵn trong số $n$

### Ví dụ

#### Input 1

```
31121987
```

#### Output 1

```
10
```

#### Input 2

```
2014
```

#### Output 2

```
6
```

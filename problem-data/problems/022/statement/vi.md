## Đề bài

Nhập vào bán kính $r$ của một hình tròn, tính chu vi và diện tích hình tròn đó theo công thức:

- Chu vi $cv = r × 2 × 3.14$

- Diện tích $dt = r × r × 3.14$

### Input

- Một số nguyên $r$ $(0 < r < 10^9)$ là bán kính hình tròn.

### Output

- Chu vi và diện tích nằm trên cùng một dòng, cách nhau bởi dấu cách, có hai chữ số thập phân.

### Ví dụ

#### Input 1

```
3
```

#### Output 1

```
18.84 28.26
```

#### Input 2

```
4
```

#### Output 2

```
25.12 50.24
```

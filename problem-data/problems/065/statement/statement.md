## Đề bài

Nhập vào một số tự nhiên $n$. Tính tổng những số tự nhiên chẵn từ 1 đến $n$.

### Input

- Một số tự nhiên $n$ ($0 < n < 10^6$).

### Output

- Một số nguyên là tổng các số tự nhiên chẵn từ 1 đến $n$.

### Ví dụ

#### Input 1

```
13
```

#### Output 1

```
42
```

#### Input 2

```
21
```

#### Output 2

```
110
```

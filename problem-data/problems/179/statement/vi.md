## Đề bài

Nhập vào một chuỗi và chuyển ký tự đầu tiên của chuỗi đó sang chữ viết hoa, các ký tự còn lại chuyển sang viết thường (capitalize)

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000.

### Output

- In chuỗi sau khi chuyển.

### Ví dụ

#### Input 1

```
tran phi an binh, lap trinh Python
```

#### Output 1

```
Tran phi an binh, lap trinh python
```

#### Input 2

```
TieN gIAng
```

#### Output 2

```
Tien giang
```

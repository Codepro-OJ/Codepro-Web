## Đề bài

Cho một số nguyên có 3 chữ số. In ra 2 chữ số đầu và 2 chữ số cuối của số vừa nhập.

### Input

- Một số tự nhiên n có 3 chữ số.

### Output

- 2 chữ số đầu và 2 chữ số cuối của n trên một dòng, cách nhau bởi dấu cách.

### Ví dụ

#### Input 1

```
673
```

#### Output 1

```
67 73
```

#### Input 2

```
602
```

#### Output 2

```
60 02
```

## Đề bài

Nhập vào ba số nguyên a, b, c đôi một khác nhau; in ra số lớn nhất. 
✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Ba số nguyên trên một dòng, cách nhau bởi dấu cách theo thứ tự là a, b, c.

- Giá trị tuyệt đối của a, b, c không vượt quá $10^9$.

### Output

- Số lớn nhất trong ba số a, b, c.

### Ví dụ

#### Input 1

```
2 5 4
```

#### Output 1

```
5
```

#### Input 2

```
7 3 9
```

#### Output 2

```
9
```

## Đề bài

Nhập vào ba số nguyên a, b, c. Tính trung bình cộng của ba số đó theo công thức: 
$TBC = \frac{(a + b + c)}{3}$ 
Kết quả có 1 chữ số thập phân.

### Input

- Gồm 3 dòng, mỗi dòng là một số nguyên a, b, c $(|a|, |b|, |c| < 10^9)$.

### Output

- Một số thực là trung bình cộng của ba số, có một chữ số thập phân.

### Ví dụ

#### Input 1

```
2
3
9
```

#### Output 1

```
4.7
```

#### Input 2

```
3
4
5
```

#### Output 2

```
4.0
```

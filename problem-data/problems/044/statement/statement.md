## Đề bài

Nhập vào chiều cao của một người (tính bằng cm), nếu chiều cao > 180 thì in ra Huu cao co, nếu chiều cao < 100 thì in ra Nam lun cute (Nấm lùn), còn lại là Binh thuong.

### Input

- Một số nguyên dương n (0 < n < 250) là chiều cao của một người.

### Output

- Kết quả là Huu cao co hoặc Nam lun cute hoặc Binh thuong.

### Ví dụ

#### Input 1

```
150
```

#### Output 1

```
Binh thuong
```

#### Input 2

```
90
```

#### Output 2

```
Nam lun cute
```

#### Input 3

```
182
```

#### Output 3

```
Huu cao co
```

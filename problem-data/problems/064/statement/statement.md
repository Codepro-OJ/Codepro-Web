## Đề bài

Nhập vào một số tự nhiên $n$. In ra số lượng số tự nhiên chia hết cho 3 trong các số từ 1 đến $n$.

### Input

- Một số tự nhiên $n$ ($0 < n < 10^6$)

### Output

- Số lượng số tự nhiên chia hết cho 3 từ 1 đến $n$.

### Ví dụ

#### Input 1

```
13
```

#### Output 1

```
4
```

#### Input 2

```
21
```

#### Output 2

```
7
```

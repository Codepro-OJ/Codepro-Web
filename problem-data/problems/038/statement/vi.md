## Đề bài

Nhập nhiệt độ t hiện tại, sau đó xác định mùa dựa trên nhiệt độ. Biết rằng:

- 0°C ≤ t ≤ 20°C → Mùa Đông (Mua Dong)

- 21°C ≤ t ≤ 25°C → Mùa Xuân (Mua Xuan)

- 26°C ≤ t ≤ 30°C → Mùa Thu (Mua Thu)

- t > 30°C → Mùa Hạ (Mua Ha)

✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Một số nguyên $t$ $(0 ≤ t < 50)$ là nhiệt độ hiện tại.

### Output

- Một dòng ghi tên mùa tương ứng với nhiệt độ.

### Ví dụ

#### Input 1

```
25
```

#### Output 1

```
Mua Xuan
```

#### Input 2

```
29
```

#### Output 2

```
Mua Thu
```

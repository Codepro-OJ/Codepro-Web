## Đề bài

Nhập vào một mã ASCII và in ra ký tự tương ứng với mã đó.

### Input

- Một dòng chứa duy nhất một số nguyên đại diện cho mã ASCII.

### Output

- In ra ký tự tương ứng với mã ASCII nhập vào.

### Ví dụ

#### Input 1

```
66
```

#### Output 1

```
B
```

#### Input 2

```
122
```

#### Output 2

```
z
```

#### Input 3

```
53
```

#### Output 3

```
5
```

## Đề bài

Nhập vào danh sách chứa các họ và tên đầy đủ. Sắp xếp danh sách theo thứ tự bằng chữ cái dựa trên tên. Nếu tên trùng nhau, sắp xếp theo họ và chữ lót.

### Input

- Dòng đầu chứa số nguyên n (số lượng họ và tên, $1 \leq n \leq 1000$).

- n dòng tiếp theo, mỗi dòng chứa một họ và tên (độ dài mỗi dòng không quá 1000 ký tự).

### Output

- In ra danh sách đã được sắp xếp, mỗi họ và tên trên một dòng.

### Ví dụ

#### Input 1

```
10
Le Bao An
Tran Phi An Binh
Le Hoai An
Le Thuy An
Le Tran Thuy An
Nguyen Ngoc Thanh Binh
Tran Minh Binh
Nguyen Thanh Binh
Tran Trieu Binh
Vo Truc Lam Binh
```

#### Output 1

```
Le Bao An
Le Hoai An
Le Thuy An
Le Tran Thuy An
Nguyen Ngoc Thanh Binh
Nguyen Thanh Binh
Tran Minh Binh
Tran Phi An Binh
Tran Trieu Binh
Vo Truc Lam Binh
```

#### Input 2

```
12  
Tran Phi An Binh
Do Gia Bao
Nguyen Hoang Bach
Nguyen Tam An
Cao Quynh Anh
Nguyen Ngoc Thanh Binh
Vo Quynh Anh
Nguyen Hoang Hai Au
Le Hoang Bach
Dang Ngo Gia Bao
Nguyen Thanh Binh
Vo Thien An
```

#### Output 2

```
Nguyen Tam An
Vo Thien An
Cao Quynh Anh
Vo Quynh Anh
Nguyen Hoang Hai Au
Le Hoang Bach
Nguyen Hoang Bach
Dang Ngo Gia Bao
Do Gia Bao
Nguyen Ngoc Thanh Binh
Nguyen Thanh Binh
Tran Phi An Binh
```

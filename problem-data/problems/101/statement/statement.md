## Đề bài

Nhập vào chiều cao $h$, vẽ hình tam giác vuông cân đặt bằng dấu $*$, với chiều dài hai cạnh góc vuông là $h$.

### Input

- Một số nguyên $h$ với điều kiện $0 < h < 10^3$.

### Output

- In ra hình tam giác vuông cân gồm $h$ dòng, mỗi dòng có số dấu $*$ tương ứng tăng dần từ 1 đến $h$ (Tam giác cân là tam giác có 2 cạnh có số dấu * bằng nhau)

### Ví dụ

#### Input 1

```
5
```

#### Output 1

```
*
**
***
****
*****
```

#### Input 2

```
8
```

#### Output 2

```
*
**
***
****
*****
******
*******
********
```

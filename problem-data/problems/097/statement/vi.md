## Đề bài

Cho một số nguyên dương $k$, hãy tìm số nguyên dương thứ $k$ thỏa điều kiện:

- Chia hết cho 3

- Không chia hết cho 9

### Input

- Một số nguyên $k$ $ (0 < k < 10^3) $.

### Output

- Số nguyên dương thứ $k$ thỏa điều kiện trên.

### Ví dụ

#### Input 1

```
3
```

#### Output 1

```
12
```

#### Input 2

```
6
```

#### Output 2

```
24
```

## Đề bài

Nhập vào số nguyên dương $k$, tính tổng $k$ số Chen đầu tiên.

Số $n$ được gọi là số Chen nếu $n$ là số nguyên tố và $n+2$ cũng là số nguyên tố. 
Số Chen thứ nhất là $3$.

Ví dụ:

- $n = 5$ là số Chen vì $5 + 2 = 7$ cũng là số nguyên tố.

- $n = 17$ là số Chen vì $17 + 2 = 19$ cũng là số nguyên tố.

- $n = 13$ không là số Chen vì $13 + 2 = 15$ không phải là số nguyên tố.

Dãy số Chen: $3, 5, 11, 17, 29, 41, 59, 71, 101, 107, \dots$.

### Input

- Một số nguyên $k$ ($|k| < 10^3$).

### Output

- Một số nguyên là tổng $k$ số Chen đầu tiên.

### Ví dụ

#### Input 1

```
4
```

#### Output 1

```
36
```

#### Input 2

```
7
```

#### Output 2

```
165
```

## Đề bài

Nhập vào tử số và mẫu số của một phân số, rút gọn và in phân số kết quả.

### Input

- Hai số nguyên $a$ và $b$ trên cùng một dòng, cách nhau bởi dấu cách ($ 0 < a, b < 10^9$), lần lượt là tử và mẫu của một phân số.

### Output

- Phân số đã rút gọn, theo dạng tử/mẫu

### Ví dụ

#### Input 1

```
15 20
```

#### Output 1

```
3/4
```

#### Input 2

```
42 49
```

#### Output 2

```
6/7
```

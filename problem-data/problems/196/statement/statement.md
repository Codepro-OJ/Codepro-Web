## Đề bài

Nhập vào một chuỗi, chuyển tất cả các ký tự viết thường thành viết hoa và các ký tự viết hoa thành viết thường.

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000.

### Output

- In ra chuỗi sau khi đã chuyển đổi ký tự.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
tRAN pHI aN bINH
```

#### Input 2

```
TiEn GiANg
```

#### Output 2

```
tIeN gIanG
```

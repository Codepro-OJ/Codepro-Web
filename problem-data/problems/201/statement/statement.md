## Đề bài

Nhập vào n ký tự, mỗi ký tự trên một dòng. Kết hợp các ký tự này thành một chuỗi.

### Input

- Dòng 1: Số nguyên n (1 ≤ n ≤ 1000).

- n dòng tiếp theo, mỗi dòng chứa một ký tự.

### Output

- Một dòng chứa chuỗi được tạo thành từ các ký tự đã nhập.

### Ví dụ

#### Input 1

```
16

a
n

n

B
i
n
h
```

#### Output 1

```
Tran Phi An Binh
```

```

#### Output 2

```
Tien Giang

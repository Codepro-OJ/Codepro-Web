## Đề bài

Viết chương trình tính toán khoảng thời gian giữa hai ngày được nhập từ người dùng. Kết quả cần hiển thị khoảng cách dưới dạng số ngày, số giờ, số phút, và số giây.

### Input

- Hai dòng đầu lần lượt chứa hai ngày theo định dạng dd-m-yyyy.

### Output

- Khoảng thời gian giữa hai ngày dưới dạng số ngày.

### Ví dụ

#### Input 1

```
30-12-2024  
01-1-2025
```

#### Output 1

```
2
```

#### Input 2

```
01-1-2025  
01-1-2025
```

#### Output 2

```
0
```

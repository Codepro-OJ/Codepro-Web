## Đề bài

Nhập vào một chuỗi s1 và thay thế tất cả các lần xuất hiện của một chuỗi s2 bằng chuỗi s3.

### Input

- Dòng 1: Chuỗi gốc s1.

- Dòng 2: Chuỗi cần tìm kiếm (chuỗi cũ) s2.

- Dòng 3: Chuỗi thay thế (chuỗi mới) s3.

- Các chuỗi có độ dài không quá 1000.

### Output

- In ra chuỗi s1 sau khi đã thay thế.

### Ví dụ

#### Input 1

```
Hom nay troi dep nen toi vui that la vui vui hanh phuc
vui
hanh phuc
```

#### Output 1

```
Hom nay troi dep nen toi hanh phuc that la hanh phuc hanh phuc hanh phuc
```

#### Input 2

```
Vinh Kim Tien Giang
i
j
```

#### Output 2

```
Vjnh Kjm Tjen Gjang
```

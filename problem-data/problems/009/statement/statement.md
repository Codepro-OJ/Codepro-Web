## Đề bài

Cho ba số nguyên $a, b, c$, hãy tính các biểu thức:

- $P = \frac{21a^2 + 5b^2}{2009c^2 + 15}$

- $Q = \frac{\sqrt{a^2 - 2b}}{3c^2 + 4}$

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Ba số nguyên $a, b, c$ $(|a|, |b|, |c| \le 10^9)$, trên cùng một dòng, cách nhau bởi dấu cách.

### Output

- $P$ và $Q$ trên một dòng, cách nhau bởi dấu cách, có bốn chữ số thập phân.

### Ví dụ

#### Input 1

```
3 4 5
```

#### Output 1

```
0.0054 0.0127
```

#### Input 2

```
4 2 5
```

#### Output 2

```
0.0071 0.0438
```

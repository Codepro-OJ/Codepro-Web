## Đề bài

Nhập vào điểm trung bình học kỳ I (HKI) và trung bình học kỳ II (HKII) của môn Tin học. Tính trung bình cả năm theo công thức:

$TBCN = (HKI + HKII × 2) / 3$

Xếp loại học sinh theo quy tắc:

- Gioi nếu $TBCN ≥ 8$

- Kha nếu $6.5 ≤ TBCN < 8$

- Trung binh nếu $5.0 ≤ TBCN < 6.5$

- Yeu nếu $3.5 ≤ TBCN < 5$

- Kem nếu $TBCN < 3.5$

✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Hai số thực trên một dòng, cách nhau bởi dấu cách: điểm HKI và HKII $(0 ≤ HKI, HKII ≤ 10)$

### Output

- Dòng 1: Giá trị TBCN (trung bình cả năm), in với 1 chữ số thập phân.

- Dòng 2: Xếp loại theo quy tắc trên.

### Ví dụ

#### Input 1

```
8 9
```

#### Output 1

```
8.7
Gioi
```

#### Input 2

```
4 7
```

#### Output 2

```
6.0
Trung binh
```

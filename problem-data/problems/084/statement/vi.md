## Đề bài

Nhập vào một số nguyên n, hãy in các chữ số của n theo thứ tự xuất hiện trong n (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($ 0 < n < 10^{18} $).

### Output

- Từng chữ số của $n$ theo thứ tự xuất hiện từ phải sang trái, các số cách nhau bởi dấu cách.

### Ví dụ

#### Input 1

```
2015
```

#### Output 1

```
5 1 0 2
```

#### Input 2

```
21052009
```

#### Output 2

```
9 0 0 2 5 0 1 2
```

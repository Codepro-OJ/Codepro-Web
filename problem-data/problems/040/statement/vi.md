## Đề bài

Nhập vào hai số nguyên a và b, kiểm tra xem:

- Nếu a và b cùng dấu thì in ra 1

- Nếu a và b khác dấu thì in ra -1

- Nếu có một trong hai số là 0 thì in ra 0

✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Hai số nguyên trên cùng một dòng, cách nhau bởi dấu cách theo thứ tự là $a$ và $b$ ($|a|, |b| ≤ 10^9$)

### Output

- Một số nguyên: 1, -1 hoặc 0

### Ví dụ

#### Input 1

```
2 5
```

#### Output 1

```
1
```

#### Input 2

```
0 3
```

#### Output 2

```
0
```

#### Input 3

```
4 -2
```

#### Output 3

```
-1
```

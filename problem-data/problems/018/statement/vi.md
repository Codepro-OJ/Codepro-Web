## Đề bài

Nhập vào tổng số giây. Hãy đổi ra giờ:phút:giây.

### Input

- Một số nguyên $n$ $(0 < n < 10^9)$ là tổng số giây.

### Output

- Kết quả đổi được theo dạng "giờ:phút:giây".

### Ví dụ

#### Input 1

```
4010
```

#### Output 1

```
1:6:50
```

#### Input 2

```
9799
```

#### Output 2

```
2:43:19
```

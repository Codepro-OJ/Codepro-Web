## Đề bài

Nhập vào một số nguyên $n$, hãy in các chữ số chẵn của $n$ theo thứ tự xuất hiện trong $n$ (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($ 0< n < 10^{18}$).

### Output

- Các chữ số chẵn trong $n$ theo thứ tự xuất hiện từ phải sang trái, cách nhau bởi dấu cách.

- Nếu không có chữ số chẵn nào thì in -.

### Ví dụ

#### Input 1

```
31121987
```

#### Output 1

```
8 2
```

#### Input 2

```
2014
```

#### Output 2

```
4 0 2
```

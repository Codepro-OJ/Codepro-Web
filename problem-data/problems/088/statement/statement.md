## Đề bài

Nhập vào số nguyên n và số nguyên x, tính tổng các chữ số lớn hơn x trong n

### Input

- Hai số nguyên $n$ ($ 0 < n < 10^{19}$) và $x$ ($0 \leq x \leq 9$) nằm trên một dòng, cách nhau bởi dấu cách.

### Output

- Tổng các chữ số lớn hơn $x$ của $n$.

### Ví dụ

#### Input 1

```
31121987 3
```

#### Output 1

```
24
```

#### Input 2

```
2014 1
```

#### Output 2

```
6
```

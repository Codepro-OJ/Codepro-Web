## Đề bài

Nhập vào một chuỗi chứa họ và tên đầy đủ s, tách và in ra phần họ và chữ lót (không bao gồm tên).

### Input

- Một dòng chứa chuỗi ký tự s có độ dài không quá 1000 ký tự.

### Output

- In ra phần họ và chữ lót (tất cả các từ trừ từ cuối cùng).

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
Tran Phi An
```

#### Input 2

```
Tien Giang
```

#### Output 2

```
Tien
```

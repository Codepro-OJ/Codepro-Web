## Đề bài

Cho một số thực $a$, hãy tính $B = \frac{1}{a}$ và in kết quả ra màn hình với năm chữ số thập phân.

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Một số thực $a$ $(|a| \le 10^9, a \neq 0)$.

### Output

- Một số thực là kết quả của B, hiển thị năm chữ số thập phân.

### Ví dụ

#### Input 1

```
2021
```

#### Output 1

```
0.00049
```

#### Input 2

```
9
```

#### Output 2

```
0.11111
```

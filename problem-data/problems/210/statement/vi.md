## Đề bài

Nhập vào một chuỗi chứa họ và tên đầy đủ s, tách và in ra phần tên (tức là từ cuối cùng trong chuỗi).

### Input

- Một dòng chứa chuỗi ký tự s có độ dài không quá 1000 ký tự.

### Output

- In ra phần tên (từ cuối cùng) trong họ và tên.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
Binh
```

#### Input 2

```
Tien Giang
```

#### Output 2

```
Giang
```

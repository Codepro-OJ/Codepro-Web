## Đề bài

Nhập vào một chuỗi s và sắp xếp các ký tự trong chuỗi theo thứ tự bảng chữ cái.

### Input

- Một dòng chứa chuỗi ký tự s có độ dài không quá 1000 ký tự.

### Output

- In ra chuỗi mới với các ký tự đã được sắp xếp theo thứ tự bảng chữ cái.

### Ví dụ

#### Input 1

```
TranPhiAnBinh
```

#### Output 1

```
ABPTahhiinnnr
```

#### Input 2

```
TienGiang
```

#### Output 2

```
GTaegiinn
```

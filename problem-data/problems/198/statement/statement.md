## Đề bài

Nhập vào một chuỗi và một ký tự phân tách, tách chuỗi thành các phần nhỏ dựa trên ký tự phân tách đó và lưu vào mảng.

### Input

- Dòng 1: Chuỗi s cần tách có độ dài không quá 1000.

- Dòng 2: Ký tự phân tách.

### Output

- In ra mảng kết quả sau khi tách chuỗi, mỗi phần tử trên một dòng.

### Ví dụ

#### Input 1

```
Tran-Phi-An-Binh
-
```

#### Output 1

```
Tran
Phi
An
Binh
```

#### Input 2

```
Vinh:Kim:Tien-Giang
:
```

#### Output 2

```
Vinh
Kim
Tien-Giang
```

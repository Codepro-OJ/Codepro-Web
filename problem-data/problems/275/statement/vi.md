## Đề bài

Viết một chương trình tính toán thời gian còn lại từ thời điểm hiện tại đến một mốc thời gian trong tương lai, bao gồm số ngày, giờ, phút và giây (ví dụ: còn bao lâu thì đến Tết nguyên đán, đến sinh nhật).

### Input

- Dòng một chứa ngày và giờ hiện tại theo định dạng dd/MM/yyyy hh:mm:ss.

- Dòng hai chứa ngày và giờ trong tương lai theo định dạng dd/MM/yyyy hh:mm:ss.

### Output

- Thời gian còn lại từ thời điểm hiện tại đến mốc thời gian đó, bao gồm số ngày, giờ, phút và giây.

### Ví dụ

#### Input 1

```
31/12/2024 20:00:00  
10/02/2025 00:00:00
```

#### Output 1

```
40 ngay 4 gio 0 phut 0 giay
```

#### Input 2

```
31/12/2023 20:00:00  
01/01/2024 00:00:00
```

#### Output 2

```
0 ngay 4 gio 0 phut 0 giay
```

## Đề bài

Viết hàm print_uppercase_letters(s) nhận vào một chuỗi $s$ và in ra tất cả các ký tự viết hoa trong chuỗi đó.

### Input

- Dòng đầu chứa một số nguyên $m$ $(1 \leq m \leq 100)$.

- $m$ dòng tiếp theo, mỗi dòng chứa một chuỗi $s$ có độ dài không quá 100.

### Output

- In ra các ký tự viết hoa trong $s$ trên một dòng.

- Nếu không có ký tự viết hoa nào, in ra dấu -.

### Ví dụ

#### Input 1

```
2
Tran Phi An Binh
Tien Giang
```

#### Output 1

```
TPAB  
TG
```

#### Input 2

```
3
hello world
This is a Test
aBcAbcabC
```

#### Output 2

```
-  
TT  
BAC
```

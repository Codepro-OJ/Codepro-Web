## Đề bài

Nhập một số nguyên từ 1 đến 10, in ra chữ tiếng Anh của số đó. 
✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Một số nguyên n từ 1 đến 10.

### Output

- Là chữ tiếng Anh tương ứng của số đó.

### Ví dụ

#### Input 1

```
3
```

#### Output 1

```
Three
```

#### Input 2

```
8
```

#### Output 2

```
Eight
```

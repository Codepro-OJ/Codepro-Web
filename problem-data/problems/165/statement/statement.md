## Đề bài

Nhập vào một chuỗi ký tự, một số nguyên $k$ và một ký tự $x$. Thay thế ký tự tại vị trí $k$ trong chuỗi bằng ký tự $x$.

### Input

- Dòng đầu tiên chứa một chuỗi ký tự có độ dài $L$ không quá 1000.

- Dòng thứ hai chứa một số nguyên $k$ $(0 \leq k < L)$.

- Dòng thứ ba chứa một ký tự $x$.

### Output

- In chuỗi sau khi đã thay thế ký tự ở vị trí $k$.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
5
R
```

#### Output 1

```
Tran Rhi An Binh
```

#### Input 2

```
Tien Giang
6
z
```

#### Output 2

```
Tien Gzang
```

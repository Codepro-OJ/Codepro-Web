# Tổng hai số

## Đề bài
Cho dữ liệu đầu vào. Hãy giải quyết bài toán theo đúng yêu cầu và in kết quả ra màn hình.

## Dữ liệu vào
Dòng đầu tiên chứa các số nguyên...

## Dữ liệu ra
In ra kết quả của bài toán.

## Ví dụ
### Input
```
2 3
```
### Output
```
5
```

## Giới hạn
- $1 \le N \le 10^5$
- Thời gian chạy: 1.0s
- Bộ nhớ: 256MB

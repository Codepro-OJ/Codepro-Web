## Đề bài

Nhập vào một số nguyên dương $n$. Đếm xem $n$ có bao nhiêu ước dương. 
Ước dương của n là các số mà n chia hết từ 1 đến n. Ví dụ n = 6 thì có các ước dương là 1, 2, 3, 6

### Input

- Một số nguyên dương $n$ ($0 < n < 10^9$).

### Output

- Một số nguyên là số lượng ước dương của $n$.

### Ví dụ

#### Input 1

```
13
```

#### Output 1

```
2
```

#### Input 2

```
21
```

#### Output 2

```
4
```

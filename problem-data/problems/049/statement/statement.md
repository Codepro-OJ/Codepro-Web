## Đề bài

Nhập vào số km đã đi, tính tiền taxi dựa theo quy định sau:

- 1 km đầu tiên: 12,000đ.

- Từ km thứ 2 đến km thứ 30: 10,000đ/km.

- Từ km thứ 31 trở đi: 9,000đ/km.

### Input

- Một số nguyên $n$ $(0 < n < 10^9)$ là số km đã đi.

### Output

- Số tiền cần trả.

### Ví dụ

#### Input 1

```
3
```

#### Output 1

```
32000
```

#### Input 2

```
40
```

#### Output 2

```
392000
```

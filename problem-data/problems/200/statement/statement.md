## Đề bài

Nhập vào một chuỗi và chuyển chuỗi đó thành một mảng (danh sách) chứa các ký tự của chuỗi. Thay ký tự tại vị trí k thành ký tự x và in mảng ký tự đó.

### Input

- Dòng 1: Chuỗi s có độ dài không quá 1000.

- Dòng 2: Số nguyên k.

- Dòng 3: Ký tự x.

### Output

- In ra mảng ký tự chứa tất cả các ký tự trong chuỗi sau khi thay đổi ký tự ở vị trí k thành ký tự x.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
3
@
```

#### Output 1

```
Tra@ Phi An Binh
```

#### Input 2

```
Vinh Kim Tien-Giang  
2
j
```

#### Output 2

```
Vijh Kim Tien-Giang
```

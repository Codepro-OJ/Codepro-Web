## Đề bài

Nhập vào một chuỗi và kiểm tra xem tất cả các ký tự trong chuỗi đó có phải là chữ số (0-9) hay không. Nếu tất cả đều là chữ số, in YES, ngược lại in NO.

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000.

### Output

- In YES nếu tất cả các ký tự trong chuỗi là chữ số.

- In NO nếu có ít nhất một ký tự không phải là chữ số.

### Ví dụ

#### Input 1

```
1234567890564
```

#### Output 1

```
YES
```

#### Input 2

```
123a56789
```

#### Output 2

```
NO
```

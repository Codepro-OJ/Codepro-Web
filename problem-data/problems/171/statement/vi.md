## Đề bài

Nhập vào một chuỗi $s1$ và một ký tự $x$. Xoá tất cả các ký tự có giá trị là $x$ trong chuỗi $s1$ và in ra chuỗi sau khi xoá.

### Input

- Dòng đầu tiên chứa chuỗi $s1$ có độ dài không quá 1000.

- Dòng thứ hai chứa một ký tự $x$ cần xoá.

### Output

- In chuỗi sau khi đã xoá tất cả các ký tự có giá trị là $x$.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
n
```

#### Output 1

```
Tra Phi A Bih
```

#### Input 2

```
Tien Giang
i
```

#### Output 2

```
Ten Gang
```

## Đề bài

Nhập vào một chuỗi và đếm số lượng từ trong chuỗi đó. Một từ được xác định là một chuỗi các ký tự liên tiếp, ngăn cách nhau bởi khoảng trắng.

### Input

- Một dòng chứa chuỗi s có độ dài không quá 1000.

### Output

- In ra số lượng từ trong chuỗi.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
4
```

#### Input 2

```
Vinh Kim Tien-Giang
```

#### Output 2

```
3
```

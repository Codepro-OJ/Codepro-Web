## Đề bài

Nhập vào chiều dài cạnh đáy $a$ và chiều cao $h$ tương ứng của một tam giác, tính diện tích tam giác đó theo công thức: $ s = \frac{a \times h}{2} $

### Input

- Một dòng gồm hai số nguyên dương $a$ và $h$ $(0 < a, h < 10^9)$, cách nhau bởi dấu cách.

### Output

- Diện tích của tam giác, in ra với một chữ số thập phân.

### Ví dụ

#### Input 1

```
3 5
```

#### Output 1

```
7.5
```

#### Input 2

```
9 7
```

#### Output 2

```
31.5
```

## Đề bài

Nhập vào điểm Toán, Văn, tiếng Anh của một học sinh là các số thực. 
Tính trung bình của học sinh đó, biết rằng điểm Toán và Văn là hệ số 2.

- Công thức: $TB=\frac{(Toan x 2 + Van x 2 + TiengAnh)}{5}$

### Input

- Ba số thực, mỗi số một dòng theo thứ tự là điểm Toán, Văn và tiếng Anh.

- Giá trị mỗi điểm từ 0 đến 10.

### Output

- Điểm trung bình, có một chữ số thập phân.

### Ví dụ

#### Input 1

```
3.0
4.5
5.6
```

#### Output 1

```
4.1
```

#### Input 2

```
6.5
8.5
9.1
```

#### Output 2

```
7.8
```

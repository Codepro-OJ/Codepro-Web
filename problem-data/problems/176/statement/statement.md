## Đề bài

Nhập vào một ký tự và in ra ký tự liền kề trước nó trong bảng chữ cái. Nếu ký tự là 'a' hoặc 'A' thì in 'z' hoặc 'Z' tương ứng.

### Input

- Một dòng chứa duy nhất một ký tự.

### Output

- In ký tự liền kề trước trong bảng chữ cái.

### Ví dụ

#### Input 1

```
b
```

#### Output 1

```
a
```

#### Input 2

```
P
```

#### Output 2

```
O
```

## Đề bài

Nhập vào một số nguyên dương $n$. Kiểm tra xem $n$ có phải là số đối xứng hay không. 
Một số $n$ được gọi là số đối xứng nếu số đảo ngược của $n$ bằng chính nó.

Ví dụ:

- n = 123321 là số đối xứng

- n = 123 không đối xứng

### Input

- Một số nguyên dương $n$ ($0 < n < 10^9$).

### Output

- Yes nếu $n$ là số đối xứng.

- No nếu $n$ không phải là số đối xứng.

### Ví dụ

#### Input 1

```
123321
```

#### Output 1

```
Yes
```

#### Input 2

```
123
```

#### Output 2

```
No
```

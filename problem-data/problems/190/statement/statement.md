## Đề bài

Nhập vào hai chuỗi s1 và s2, tìm vị trí đầu tiên mà chuỗi s2 xuất hiện trong chuỗi s1. Nếu s2 không xuất hiện trong s1, in -1.

### Input

- Dòng một: Chuỗi s1 (chuỗi cần tìm).

- Dòng hai: Chuỗi s2 (chuỗi chứa).

- Các chuỗi có độ dài không quá 1000 ký tự.

### Output

- In vị trí đầu tiên mà s2 xuất hiện trong s1 (vị trí bắt đầu từ 0).

- Nếu s2 không xuất hiện trong s1 thì in -1.

### Ví dụ

#### Input 1

```
Nha toi co nhieu hoa mai hoa cuc hoa hue hoa
hoa
```

#### Output 1

```
17
```

#### Input 2

```
Toi o Vinh Kim Tien Giang Viet Nam
Z
```

#### Output 2

```
-1
```

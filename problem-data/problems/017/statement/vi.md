## Đề bài

Nhập một số tiền $N$ đồng, đổi ra xem được bao nhiêu tờ 5.000 đồng, bao nhiêu tờ 2.000 đồng, bao nhiêu tờ 1.000 đồng sao cho tổng số tờ là ít nhất.

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Một số nguyên $N$ ($0 < N < 10^9$, N là số chia hết cho 1000)  là số tiền cần đổi.

### Output

- Một dòng gồm ba số theo thứ tự là số tờ 5.000, số tờ 2.000 và số tờ 1.000 cách nhau một dấu cách.

### Ví dụ

#### Input 1

```
43000
```

#### Output 1

```
8 1 1
```

#### Input 2

```
51000
```

#### Output 2

```
10 0 1
```

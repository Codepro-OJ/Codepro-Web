## Đề bài

Nhập vào một ký tự và in ra ký tự liền kề sau nó trong bảng chữ cái. Nếu ký tự là 'z' hoặc 'Z' thì in 'a' hoặc 'A' tương ứng.

### Input

- Một dòng chứa duy nhất một ký tự.

### Output

- In ký tự liền kề sau trong bảng chữ cái.

### Ví dụ

#### Input 1

```
a
```

#### Output 1

```
b
```

#### Input 2

```
P
```

#### Output 2

```
Q
```

## Đề bài

Cho một số nguyên $a$, hãy tính $B = a - 2$ và in kết quả ra màn hình.

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Một số nguyên $a$ $(|a| \le 10^9)$.

### Output

- Một số nguyên duy nhất là kết quả của $B$.

### Ví dụ

#### Input 1

```
2009
```

#### Output 1

```
2007
```

#### Input 2

```
1
```

#### Output 2

```
-1
```

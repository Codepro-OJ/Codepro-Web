## Đề bài

Nhập vào một chuỗi và kiểm tra xem tất cả các ký tự trong chuỗi đó có phải là ký hiệu (là các ký tự không phải chữ cái và chữ số) hay không. Nếu tất cả đều là ký hiệu, in YES, ngược lại in NO.

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000.

### Output

- In YES nếu tất cả các ký tự trong chuỗi là ký hiệu.

- In NO nếu có ít nhất một ký tự là chữ cái hoặc chữ số.

### Ví dụ

#### Input 1

```
@#&$%*!
```

#### Output 1

```
YES
```

#### Input 2

```
1234#&@
```

#### Output 2

```
NO
```

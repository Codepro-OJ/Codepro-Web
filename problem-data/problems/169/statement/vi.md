## Đề bài

Nhập vào chuỗi $s1$, $s2$ và một số nguyên $k$. Chèn chuỗi $s2$ vào vị trí $k$ của chuỗi $s1$.

### Input

- Dòng đầu tiên chứa chuỗi $s1$ có độ dài $L$ không quá 1000.

- Dòng thứ hai chứa chuỗi $s2$ có độ dài không quá 1000.

- Dòng thứ ba chứa số nguyên $k$ $(0 \leq k \leq L)$.

### Output

- In chuỗi sau khi đã chèn $s2$ vào $s1$.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
Tien Giang
8
```

#### Output 1

```
Tran PhiTien Giang An Binh
```

#### Input 2

```
Tien Giang
Viet Nam
9
```

#### Output 2

```
Tien GianViet Namg
```

## Đề bài

Nhập vào một số nguyên dương $n$. Kiểm tra xem $n$ có phải là số Pronic hay không.

Một số nguyên $n$ được gọi là số Pronic nếu:

- $n = m \times (m+1)$, với $m$ là một số tự nhiên.

- Nghĩa là $n$ phân tích được thành tích của hai số tự nhiên liên tiếp.

Ví dụ:

- n = 6 là số Pronic vì 6 = 2 x 3

- n = 20 là số Pronic vì 20 = 4 x 5

### Input

- Một số nguyên dương $n$ ($0 < n < 10^9$).

### Output

- Yes nếu $n$ là số Pronic.

- No nếu $n$ không phải là số Pronic.

### Ví dụ

#### Input 1

```
20
```

#### Output 1

```
Yes
```

#### Input 2

```
21
```

#### Output 2

```
No
```

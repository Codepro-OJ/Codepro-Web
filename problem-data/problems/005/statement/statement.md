## Đề bài

Cho một số nguyên $a$, hãy tính $B1 = a^2$ và $B2 = a^5$ và in kết quả ra màn hình.

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Một số nguyên $a$ $(|a| \le 10^9)$.

### Output

- Hai số nguyên lần lượt là kết quả của B1 và B2, mỗi số trên một dòng.

### Ví dụ

#### Input 1

```
4
```

#### Output 1

```
16
1024
```

#### Input 2

```
7
```

#### Output 2

```
49
16807
```

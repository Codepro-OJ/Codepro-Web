## Đề bài

Nhập vào số nguyên $x$ và số tự nhiên $n$, tính $x^n$.

$x^n$ là kết quả của việc nhân số $x$ với chính nó $n$ lần: $x^n = x \cdot x \cdot x \cdot \ldots \cdot x \quad (\text{n lần})$

#### Ví dụ:

- $x = 3, n = 4$: 
$  3^4 = 3 \cdot 3 \cdot 3 \cdot 3 = 81$

- $x = -2, n = 3$: 
$  (-2)^3 = (-2) \cdot (-2) \cdot (-2) = -8 $

### Input

- Dòng một: Một số nguyên $x$ ($|x| < 10^2$).

- Dòng hai: Một số tự nhiên $n$ ($0 \leq n < 10$).

### Output

- Một số nguyên là kết quả của $x^n$.

### Ví dụ

#### Input 1

```
3  
4
```

#### Output 1

```
81
```

#### Input 2

```
-2  
3
```

#### Output 2

```
-8
```

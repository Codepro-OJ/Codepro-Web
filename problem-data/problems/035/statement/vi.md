## Đề bài

Nhập tuổi của một người, trả lời:

- Thieu nhi nếu 0 < tuổi ≤ 11

- Thieu nien nếu 11 < tuổi ≤ 25

- Trung nien nếu 25 < tuổi ≤ 50

- Lao nien nếu tuổi >50

✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Một số nguyên (0 < t ≤ 150) là tuổi của một người.

### Output

- Là "Thieu nhi", "Thieu nien", "Trung nien" hoặc "Lao nien".

### Ví dụ

#### Input 1

```
31
```

#### Output 1

```
Trung nien
```

#### Input 2

```
8
```

#### Output 2

```
Thieu nhi
```

## Đề bài

Nhập vào một chuỗi và chuyển tất cả các ký tự trong chuỗi đó sang chữ viết thường.

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000.

### Output

- In chuỗi sau khi tất cả các ký tự đã được chuyển sang chữ viết thường.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
tran phi an binh
```

#### Input 2

```
Tien Giang
```

#### Output 2

```
tien giang
```

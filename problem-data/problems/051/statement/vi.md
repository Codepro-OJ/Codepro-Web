## Đề bài

Nhập vào một số nguyên n, kiểm tra n là số chẵn hay lẻ.

- Nếu n là số chẵn, kiểm tra tiếp: 

n là số dương, số âm, hay số không.

- Nếu n là số lẻ, kiểm tra tiếp: 

n là số dương hay số âm.

### Input

- Một số nguyên n (|n| $\leq 10^9$).

### Output

- Dòng 1: Chan hoặc Le.

- Dòng 2: Là một trong những từ Duong, Am, Khong.

### Ví dụ

#### Input 1

```
9
```

#### Output 1

```
Le
Duong
```

#### Input 2

```
-10
```

#### Output 2

```
Chan
Am
```

#### Input 3

```
0
```

#### Output 2

```
Chan
Khong
```

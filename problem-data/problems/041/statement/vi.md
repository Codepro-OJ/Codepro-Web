## Đề bài

Nhập vào một số nguyên $n$, kiểm tra xem $n$ có chia hết cho 6 hay không.

✅ (Sử dụng if ... else...)

### Input

- Một số nguyên $n$ ($|n| ≤ 10^9$)

### Output

- Kết quả là Yes nếu chia hết cho 6, ngược lại là No

### Ví dụ

#### Input 1

```
22
```

#### Output 1

```
No
```

#### Input 2

```
30
```

#### Output 2

```
Yes
```

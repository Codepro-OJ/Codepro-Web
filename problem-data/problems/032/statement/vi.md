## Đề bài

Nhập vào thời gian chạy của hai bạn An và Bình, in ra tên của bạn chạy nhanh hơn. Nếu hai bạn có thời gian chạy bằng nhau thì in ra "Bang nhau". 
✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Hai số nguyên $a$ và $b$ $ (0 < a, b ≤ 10⁴)$ trên cùng một dòng, cách nhau bởi dấu cách, là thời gian chạy lần lượt của An và Bình (tính bằng giây).

### Output

- Là tên bạn nhanh hơn hoặc "Bang nhau".

### Ví dụ

#### Input 1

```
180 191
```

#### Output 1

```
An nhanh hon
```

#### Input 2

```
213 201
```

#### Output 2

```
Binh nhanh hon
```

#### Input 3

```
200 200
```

#### Output 3

```
Bang nhau
```

## Đề bài

Nhập vào chu vi của một hình tròn, tính diện tích hình tròn đó.

### Input

- Một số thực $a$ $(0 < a < 10^9)$ là chu vi của một hình tròn.

### Output

- Diện tích của hình tròn, có hai chữ số thập phân.

### Ví dụ

#### Input 1

```
18.84
```

#### Output 1

```
28.26
```

#### Input 2

```
25.12
```

#### Output 2

```
50.24
```

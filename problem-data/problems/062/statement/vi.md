## Đề bài

Nhập vào một số tự nhiên $n$. Tính tổng những số tự nhiên từ 1 đến $n$.

### Input

- Một số tự nhiên $n$ ($0 < n < 10^6$)

### Output

- Một số nguyên là tổng của các số tự nhiên từ 1 đến $n$.

### Ví dụ

#### Input 1

```
3
```

#### Output 1

```
6
```

#### Input 2

```
6
```

#### Output 2

```
21
```

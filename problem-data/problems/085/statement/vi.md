## Đề bài

Nhập vào một số nguyên $n$, hãy tính tổng các chữ số của $n$ (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($0 < n < 10^{19}$).

### Output

- Tổng các chữ số của $n$.

### Ví dụ

#### Input 1

```
31122023
```

#### Output 1

```
14
```

#### Input 2

```
2009
```

#### Output 2

```
11
```

## Đề bài

Nhập vào một số nguyên dương a có 8 chữ số. Tìm chữ số lớn nhất và nhỏ nhất của a.

### Input

- Một số nguyên dương a có 8 chữ số.

### Output

- Chữ số lớn nhất và nhỏ nhất của a trên một dòng, cách nhau bởi dấu cách.

### Ví dụ

#### Input 1

```
21052004
```

#### Output 1

```
5 0
```

#### Input 2

```
15111977
```

#### Output 2

```
9 1
```

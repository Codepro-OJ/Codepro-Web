## Đề bài

Nhập vào một ký tự và in ra mã ASCII tương ứng của ký tự đó.

### Input

- Một dòng chứa duy nhất một ký tự.

### Output

- In ra mã ASCII của ký tự nhập vào.

### Ví dụ

#### Input 1

```
B
```

#### Output 1

```
66
```

#### Input 2

```
z
```

#### Output 2

```
122
```

#### Input 3

```
5
```

#### Output 3

```
53
```

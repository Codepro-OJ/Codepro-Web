## Đề bài

Nhập vào một chuỗi ký tự, hai số nguyên $start$ và $end$. Tạo chuỗi con từ vị trí $start$ đến $end$.

### Input

- Dòng đầu tiên chứa một chuỗi ký tự có độ dài không quá 1000.

- Dòng thứ hai chứa số nguyên $start$ $(0 \leq start < L)$.

- Dòng thứ ba chứa số nguyên $end$ $(start \leq end \leq L)$.

### Output

- In chuỗi con được tạo từ vị trí $start$ đến $end$.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
5
10
```

#### Output 1

```
Phi An
```

#### Input 2

```
Tien Giang
2
6
```

#### Output 2

```
en Gi
```

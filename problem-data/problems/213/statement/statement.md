## Đề bài

Nhập vào một mảng gồm n xâu, sắp xếp mảng theo thứ tự tăng dần của chiều dài từng xâu. Nếu hai xâu có cùng độ dài, giữ nguyên thứ tự xuất hiện ban đầu.

### Input

- Dòng đầu chứa số nguyên n ($1 \leq n \leq 1000$).

- n dòng tiếp theo, mỗi dòng chứa một xâu ký tự có độ dài không quá 1000.

### Output

- In ra mảng xâu đã được sắp xếp, mỗi xâu trên một dòng.

### Ví dụ

#### Input 1

```
4
Tran Phi An Binh
Vinh Kim
TTS
Tien Giang
```

#### Output 1

```
TTS
Vinh Kim
Tien Giang
Tran Phi An Binh
```

#### Input 2

```
3
Programing
HeLo
abcxy
```

#### Output 2

```
HeLo
abcxy
Programing
```

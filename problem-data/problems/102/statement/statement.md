## Đề bài

Nhập vào chiều dài $d$ và chiều rộng $r$, vẽ hình chữ nhật đặc bằng dấu * với chiều dài là $d$ và chiều rộng là $r$.

### Input

- Một dòng gồm hai số nguyên $d$ và $r$ ($0 < d, r < 10^3$).

### Output

- Hình chữ nhật đặc được vẽ bằng dấu * với chiều dài $d$ và chiều rộng $r$.

### Ví dụ

#### Input 1

```
5 3
```

#### Output 1

```
*****
*****
*****
```

#### Input 2

```
7 4
```

#### Output 2

```
*******
*******
*******
*******
```

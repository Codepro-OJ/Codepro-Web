## Đề bài

Nhập vào một số nguyên $n$, hãy tìm chữ số chẵn nhỏ nhất của $n$ (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($0< n < 10^{19}$).

### Output

- Chữ số chẵn nhỏ nhất của $n$, nếu không có chữ số chẵn nào thì in $-$.

### Ví dụ

#### Input 1

```
32145786
```

#### Output 1

```
2
```

#### Input 2

```
2530
```

#### Output 2

```
0
```

## Đề bài

Nhập vào tổng điểm $d$ của một học sinh và đánh giá kết quả học tập theo các tiêu chí sau:

- Nếu $d \geq 80$: Loại A 

Nếu $d \geq 90$: Xuất sắc 
Nếu $80 \leq d < 90$: Giỏi

- Nếu $50 \leq d < 80$: Loại B 

Nếu $d \geq 65$: Khá 
Nếu $50 \leq d < 65$: Trung bình

- Nếu $d < 50$: Loại C 

Nếu $d \geq 35$: Yếu 
Nếu $d < 35$: Kém

### Input

- Một số nguyên $d$ $(0 < d \leq 10^2)$.

### Output

- Dòng 1: Loai A, Loai B, hoặc Loai C.

- Dòng 2: Mô tả chi tiết (Xuat sac, Gioi, Kha, Trung binh, Yeu, hoặc Kem).

### Ví dụ

#### Input 1

```
92
```

#### Output 1

```
Loai A
Xuat sac
```

#### Input 2

```
51
```

#### Output 2

```
Loai B
Trung binh
```

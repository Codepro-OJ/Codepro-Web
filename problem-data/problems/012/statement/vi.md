## Đề bài

Nhập vào một số nguyên $a$ có 2 chữ số. Tìm chữ số hàng đơn vị và chữ số hàng chục của số nguyên $a$.

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Một số nguyên $a$ $(10 \leq a \leq 99)$.

### Output

- Chữ số hàng đơn vị và chữ số hàng chục trên một dòng, cách nhau bởi dấu cách.

### Ví dụ

#### Input 1

```
12
```

#### Output 1

```
2 1
```

#### Input 2

```
30
```

#### Output 2

```
0 3
```

## Đề bài

Nhập vào hai số nguyên $m$ và $n$ ($m \leq n$). Tính tổng các số nguyên từ $m$ đến $n$.

### Input

- Hai số nguyên dương $m$ và $n$ ($0 < m \leq n < 10^6$), mỗi số trên một dòng.

### Output

- Một số là tổng các số nguyên từ $m$ đến $n$.

### Ví dụ

#### Input 1

```
3
7
```

#### Output 1

```
25
```

#### Input 2

```
5
12
```

#### Output 2

```
68
```

## Đề bài

Nhập vào một chuỗi và kiểm tra xem tất cả các ký tự trong chuỗi đó có phải là chữ cái (từ $a$ đến $z$ hoặc $A$ đến $Z$) hay không. 
Nếu tất cả đều là chữ cái thì in "YES", ngược lại in "NO".

### Input

- Một dòng chứa chuỗi ký tự, độ dài không quá $1000$.

### Output

- In ra "YES" nếu tất cả các ký tự trong chuỗi là chữ cái.

- In ra "NO" nếu có ít nhất một ký tự không phải là chữ cái.

### Ví dụ

#### Input 1

```
TranPhiAnBinh
```

#### Output 1

```
YES
```

#### Input 2

```
Tien Giang
```

#### Output 2

```
NO
```

#### Input 3

```
HelloWorld!
```

#### Output 3

```
NO
```

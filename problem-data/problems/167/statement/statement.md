## Đề bài

Nhập vào một chuỗi ký tự $s1$. Tạo chuỗi $s2$ bằng cách loại bỏ tất cả khoảng trắng trong chuỗi $s1$ và in kết quả.

### Input

- Một dòng chứa chuỗi ký tự $s1$ có độ dài không quá 1000.

### Output

- In chuỗi $s2$ sau khi đã loại bỏ tất cả khoảng trắng.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
TranPhiAnBinh
```

#### Input 2

```
TienGiang
```

#### Output 2

```
TienGiang
```

## Đề bài

Nhập vào một số nguyên $n$, kiểm tra xem $n$ có lớn hơn 100 hay không.

✅ (Sử dụng if ... else...)

### Input

- Một số nguyên $n$ ($|n| ≤ 10^9$)

### Output

- Kết quả là Yes nếu $n > 100$, ngược lại là No

### Ví dụ

#### Input 1

```
22
```

#### Output 1

```
No
```

#### Input 2

```
101
```

#### Output 2

```
Yes
```

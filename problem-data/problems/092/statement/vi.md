## Đề bài

Nhập vào một số nguyên $n$, hãy tìm chữ số nhỏ nhất của $n$ (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($0< n < 10^{19}$).

### Output

- Chữ số nhỏ nhất của $n$.

### Ví dụ

#### Input 1

```
31121987
```

#### Output 1

```
1
```

#### Input 2

```
2030
```

#### Output 2

```
0
```

## Đề bài

Cho một số nguyên $a$, hãy tính $B = a : 3$ và in kết quả ra màn hình với hai chữ số thập phân.

(⚠ Nếu em chưa chắc là mình đã hiểu đề bài, hãy xem  📺 video hướng dẫn phía dưới trước khi bắt đầu code)

### Input

- Một số nguyên $a$ $(|a| \le 10^9)$.

### Output

- Một số thực duy nhất là kết quả của $B$, có hai chữ số thập phân.

### Ví dụ

#### Input 1

```
13
```

#### Output 1

```
4.33
```

#### Input 2

```
8
```

#### Output 2

```
2.67
```

#### Input 3

```
-7
```

#### Output 3

```
-2.33
```

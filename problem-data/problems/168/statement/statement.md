## Đề bài

Nhập vào một chuỗi ký tự $s$. Kiểm tra xem chuỗi có đối xứng (palindrome) hay không. Nếu chuỗi đối xứng, in YES, nếu không in NO.
Một chuỗi s được gọi là đỗi xứng khi đọc từ trái sang phải hoặc từ phải sang trái thì đều cho ra cùng một chuỗi (có phân biệt chữ hoa, thường)

### Input

- Một dòng chứa chuỗi ký tự $s$ có độ dài không quá 1000.

### Output

- In YES nếu chuỗi là chuỗi đối xứng.

- In NO nếu chuỗi không đối xứng.

### Ví dụ

#### Input 1

```
radar
```

#### Output 1

```
YES
```

#### Input 2

```
Tran Phi An Binh
```

#### Output 2

```
NO
```

#### Input 3

```
Level
```

#### Output 3

```
NO
```

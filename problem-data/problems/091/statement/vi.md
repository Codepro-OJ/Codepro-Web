## Đề bài

Nhập vào một số nguyên $n$, hãy tìm chữ số lớn nhất của $n$ (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($0 < n < 10^{19}$).

### Output

- Chữ số lớn nhất của $n$.

### Ví dụ

#### Input 1

```
31121987
```

#### Output 1

```
9
```

#### Input 2

```
2030
```

#### Output 2

```
3
```

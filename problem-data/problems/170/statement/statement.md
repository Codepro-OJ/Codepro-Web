## Đề bài

Nhập vào chuỗi $s1$ và số nguyên $k$. Xoá ký tự thứ $k$ trong chuỗi $s1$ và in ra chuỗi sau khi xoá.

### Input

- Dòng đầu tiên chứa chuỗi $s1$ có độ dài $L$ không quá 1000.

- Dòng thứ hai chứa số nguyên $k$ $(0 \leq k < L)$.

### Output

- In ra chuỗi sau khi đã xoá ký tự thứ $k$.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
10
```

#### Output 1

```
Tran Phi A Binh
```

#### Input 2

```
Tien Giang
7
```

#### Output 2

```
Tien Ging
```

## Đề bài

Nhập vào một chuỗi và tìm từ có độ dài nhỏ nhất trong chuỗi đó.

### Input

- Một dòng chứa chuỗi ký tự s có độ dài không quá 1000 ký tự.

### Output

- In ra từ có độ dài nhỏ nhất.

- Nếu có nhiều từ cùng độ dài nhỏ nhất, in từ đầu tiên tính từ trái sang phải.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
An
```

#### Input 2

```
Tien Giang
```

#### Output 2

```
Tien
```

## Đề bài

Nhập vào một chuỗi và kiểm tra xem chuỗi đó có phải là kiểu tên hay không, nghĩa là ký tự đầu tiên của mỗi từ viết hoa, các ký tự còn lại viết thường. Nếu đúng, in Yes, ngược lại in No.

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000.

### Output

- In Yes nếu chuỗi đúng kiểu tên.

- In No nếu không đúng kiểu tên.

### Ví dụ

#### Input 1

```
Tran Phi An Binh
```

#### Output 1

```
Yes
```

#### Input 2

```
Tran phi An Binh
```

#### Output 2

```
No
```

## Đề bài

Nhập vào hai số nguyên $m$ và $n$ ($m \leq n$). Đếm xem trong các số nguyên từ $m$ đến $n$, có bao nhiêu số chia hết cho $3$.

### Input

- Hai số nguyên dương $m$ và $n$ ($0 < m \leq n < 10^6$), mỗi số trên một dòng.

### Output

- Một số nguyên là số lượng các số chia hết cho $3$ từ $m$ đến $n$.

### Ví dụ

#### Input 1

```
21
32
```

#### Output 1

```
4
```

#### Input 2

```
11
13
```

#### Output 2

```
1
```

## Đề bài

In ra bảng cửu chương của số tự nhiên $n$ theo định dạng phép nhân.

### Input

- Một số nguyên $n$ ($1 < n \leq 100$).

### Output

- Bảng cửu chương của $n$ từ 1 đến 9, theo định dạng: "i x n = kết quả", các số và chữ cách nhau bởi dấu cách.

### Ví dụ

#### Input 1

```
5
```

#### Output 1

```
1 x 5 = 5
2 x 5 = 10
3 x 5 = 15
4 x 5 = 20
5 x 5 = 25
6 x 5 = 30
7 x 5 = 35
8 x 5 = 40
9 x 5 = 45
```

#### Input 2

```
2
```

#### Output 2

```
1 x 2 = 2
2 x 2 = 4
3 x 2 = 6
4 x 2 = 8
5 x 2 = 10
6 x 2 = 12
7 x 2 = 14
8 x 2 = 16
9 x 2 = 18
```

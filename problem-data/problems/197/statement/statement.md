## Đề bài

Nhập vào một chuỗi ký tự và một số nguyên n, thêm đủ số lượng chữ số 0 vào bên trái chuỗi sao cho độ dài chuỗi bằng n (zfill).

### Input

- Dòng 1: Chuỗi s có độ dài không quá 1000.

- Dòng 2: Số nguyên n (độ dài mong muốn).

### Output

- In ra chuỗi s sau khi thêm đủ số 0 vào bên trái.

### Ví dụ

#### Input 1

```
25
6
```

#### Output 1

```
000025
```

#### Input 2

```
123
5
```

#### Output 2

```
00123
```

## Đề bài

Nhập vào số điện tiêu thụ (tính bằng kWh) trong một tháng và tính tiền điện sử dụng trong tháng đó.

- 50 kWh đầu tiên: giá 600đ/kWh.

- 50 kWh tiếp theo: giá 800đ/kWh.

- 100 kWh tiếp theo: giá 1100đ/kWh.

- Phần còn lại: giá 1500đ/kWh.

### Input

- Một số nguyên $n$ $(0 < n < 10^9)$, là số kWh điện đã sử dụng.

### Output

- Số tiền cần trả.

### Ví dụ

#### Input 1

```
40
```

#### Output 1

```
24000
```

#### Input 2

```
70
```

#### Output 2

```
46000
```

#### Input 3

```
110
```

#### Output 3

```
81000
```

#### Input 4

```
230
```

#### Output 4

```
225000
```

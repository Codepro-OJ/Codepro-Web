## Đề bài

Viết chương trình tính toán khoảng thời gian giữa hai giờ trong cùng một ngày. Kết quả cần hiển thị dưới dạng số giờ, số phút, và số giây.

### Input

- Hai dòng, mỗi dòng chứa một giờ theo định dạng hh:m:ss.

### Output

- Khoảng thời gian giữa hai giờ dưới dạng: 
X giờ, Y phút, Z giây

### Ví dụ

#### Input 1

```
14:00:00  
16:45:03
```

#### Output 1

```
2 gio, 45 phut, 3 giay
```

#### Input 2

```
23:55:00  
00:02:30
```

#### Output 2

```
0 gio, 7 phut, 30 giay
```

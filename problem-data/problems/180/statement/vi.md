## Đề bài

Nhập vào một chuỗi và chuyển ký tự đầu tiên của mỗi từ trong chuỗi đó sang chữ viết hoa, các ký tự còn lại viết thường (kiểu tên).

### Input

- Một dòng chứa chuỗi ký tự có độ dài không quá 1000.

### Output

- In chuỗi sau khi tất cả ký tự đầu của mỗi từ đã được chuyển sang chữ viết hoa.

### Ví dụ

#### Input 1

```
tran phi an binh
```

#### Output 1

```
Tran Phi An Binh
```

#### Input 2

```
TieN gIAng
```

#### Output 2

```
Tien Giang
```

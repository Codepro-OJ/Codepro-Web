## Đề bài

Nhập vào một số nguyên $n$, hãy tìm chữ số lẻ lớn nhất của $n$ (không sử dụng kiểu string).

### Input

- Một số nguyên $n$ ($0 < n < 10^{19}$).

### Output

- Chữ số lẻ lớn nhất của $n$, nếu không có chữ số lẻ nào thì in $-$.

### Ví dụ

#### Input 1

```
32145786
```

#### Output 1

```
7
```

#### Input 2

```
2531
```

#### Output 2

```
5
```

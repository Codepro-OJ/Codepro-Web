## Đề bài

Nhập vào cạnh $a$ của một hình vuông, tính chu vi và diện tích của hình vuông đó theo công thức $cv = a × 4$, $dt = a × a$.

### Input

- Một số nguyên $a$ $(0 < a < 10^9)$ là cạnh hình vuông.

### Output

- Chu vi và diện tích nằm trên cùng một dòng, cách nhau bởi dấu cách.

### Ví dụ

#### Input 1

```
2
```

#### Output 1

```
8 4
```

#### Input 2

```
3
```

#### Output 2

```
12 9
```

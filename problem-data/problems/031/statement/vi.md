## Đề bài

Nhập vào điểm trung bình của hai bạn An và Bình, in ra tên của bạn giỏi hơn. Nếu hai bạn bằng điểm trung bình thì in ra 'Bang nhau'. 
✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Dòng một là điểm trung bình của bạn An (số thực).

- Dòng hai là điểm trung bình của bạn Bình (số thực).

- Các điểm từ 0 đến 10.

### Output

- Là tên bạn giỏi hơn hoặc "Bang nhau".

### Ví dụ

#### Input 1

```
8.2
6.5
```

#### Output 1

```
An gioi hon
```

#### Input 2

```
5.3
6.7
```

#### Output 2

```
Binh gioi hon
```

#### Input 3

```
8.0
8.0
```

#### Output 3

```
Bang nhau
```

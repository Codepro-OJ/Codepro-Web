## Đề bài

Nhập một tháng, cho biết tháng đó thuộc mùa nào (Xuân, Hạ, Thu, Đông), biết rằng:

- Tháng 2, 3, 4 → Mùa Xuân

- Tháng 5, 6, 7 → Mùa Hạ

- Tháng 8, 9, 10 → Mùa Thu

- Tháng 11, 12, 1 → Mùa Đông

✅ (Sử dụng if... Không sử dụng if ... else...)

### Input

- Một số nguyên $t$ $(0 < t < 13)$ là một tháng trong năm.

### Output

- Một dòng: tên mùa tương ứng với tháng đã cho (không dấu tiếng Việt).

### Ví dụ

#### Input 1

```
2
```

#### Output 1

```
Mua Xuan
```

#### Input 2

```
8
```

#### Output 2

```
Mua Thu
```
